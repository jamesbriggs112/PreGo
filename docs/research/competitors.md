## Where Prego overlaps

- Accessibility engines (axe-core, as Deque, Screaming Frog, Pa11y and Sitebulb use; IBM Equal Access).
- Crawling, SEO, spelling and broken links (Screaming Frog, Sitebulb, Silktide, Siteimprove).
- Lighthouse performance (Unlighthouse, Lighthouse CI, Semrush, Ahrefs).
- Cookie and tracker checks (Cookiebot, CookieYes, Blacklight).
- Search and AI-answer readiness (Siteimprove, Silktide, Semrush are moving here).

## Where Prego is different

- Local only, with no paid services, across every category. The only local competitors (Screaming Frog, Sitebulb Desktop) are SEO-first; every multi-category suite is cloud, so client data goes to the vendor.
- Accessibility, SEO, performance, passive security, consent and go-live checks in one run.
- Personas, tasks, navigation tests, a local-AI walkthrough, app exploration and journey replay. No audit tool reviewed does this.
- A report pack for different readers, cross-referenced to de-duplicated tickets, with CSV for Jira, Linear, Trello and Productive.
- Analytics and Search Console weighting from CSV, with no API connection.
- Built for UK agencies: British English, UK law in the possible legal risks panel.

## Gaps against competitors

- Scheduled monitoring and alerts.
- Trends over time.
- Multiple users, roles and SSO.
- PDF and document accessibility.
- Two-way issue tracker sync (rather than CSV).
- CI/CD gating.
- Guided manual testing and expert services; accessibility statement and VPAT help.
- Very large estates (100k+ pages).
- Off-site SEO data (backlinks, rankings).
